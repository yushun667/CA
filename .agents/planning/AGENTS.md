# AGENTS.md — 项目规划

本目录是工作顺序和当前状态的权威来源。

- [roadmap.md](roadmap.md)：评估里程碑、范围或阶段依赖时读取；中文对照 roadmap.zh.md，一致性记录 roadmap.i18n.yaml。
- [current-phase.md](current-phase.md)：开始工作、拆分当前阶段或选择下一步时读取；中文对照 current-phase.zh.md，一致性记录 current-phase.i18n.yaml。
- [progress.md](progress.md)：报告状态、交接或更新完成情况时读取；中文对照 progress.zh.md，一致性记录 progress.i18n.yaml。
- [archive/AGENTS.md](archive/AGENTS.md)：仅在回顾已完成阶段时进入。

只保留当前可执行状态；完成阶段的详细记录移入 `archive/`，并保持三个现行文件简短一致。

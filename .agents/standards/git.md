# Git 与提交规范

根 `AGENTS.md` 的五条 Git 规约不可被本文件或子目录削弱。

## 提交前

1. 用 `git status --short` 确认所有要保留的修改均受 Git 管理；临时或生成内容应删除或明确忽略。
2. 只暂存服务于一个逻辑目的的文件和片段。代码、测试、配套文档可以同提交，前提是缺少任一部分都会使该目的不完整。
3. 根据暂存内容执行代码审查、文档审查或两者，并在审查后再次检查最终暂存差异。
4. 运行 `python3 .agents/validate.py --root . --mode precommit`；失败时禁止提交。

## Commit 信息

标题简洁说明结果；正文必须包含独立的原因说明，例如：

```text
<type>(<scope>): <实现的结果>

Reason: <为什么现在需要这项修改，以及它解决什么问题>
```

只写“更新文件”“修复问题”或改动清单不满足原因要求。未经用户明确要求，agent 不执行 commit。

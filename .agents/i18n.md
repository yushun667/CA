# 双语文档契约

新编写或更新的项目说明、架构、规划、决策与问题记录采用三件套：`foo.md`（英文）、`foo.zh.md`（中文）、`foo.i18n.yaml`（两边文件名与 SHA-256）。目录 `AGENTS.md`、技能入口、操作规范和未填写模板作为单一规则入口维护，不复制导航树。

- 两种语言逐节对应，术语一致；Status、Date 等机器字段和生命周期值保持一致。
- 修改一边时同步另一边并更新哈希；移动、归档和删除时整组三件套一起处理。
- 既有项目保留其语言契约。批量翻译存量资料须用户明确要求；初始化时只配对本次新写的实质文档。
- 冻结档案不补译、不改写；归档前更新对应一致性记录。
- 用户明确选择单语时，移除本契约及全部入链，并在决策中记录语言政策。

一致性记录示例：

```yaml
version: 1
updated: YYYY-MM-DD
en:
  file: foo.md
  sha256: <英文文件的 SHA-256>
zh:
  file: foo.zh.md
  sha256: <中文文件的 SHA-256>
```

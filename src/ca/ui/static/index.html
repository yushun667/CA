    Explore a CA index

    CA analyzes operating-system source code from its real build: exact compile arguments, Clang AST, CFG and data-flow facts stored in SQLite. This local page is a read-only view over that database.

    What you can inspect

    • Symbol search — exact names and substring matches across every translation unit.
    • Function detail — signature, source location, branches, assignments, return paths and resource operations.
    • Call graph — SVG traversal with direct edges and dashed candidate edges marking the possible target set.
    • Callers / callees — merged direct calls and cross-TU callback candidates.
    • Stats / callbacks — table counts, shard provenance, and function-pointer registration facts.
